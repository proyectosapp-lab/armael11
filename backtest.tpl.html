Backtest de ligas

¿El modelo le gana a la vara en esta liga? Se corre en GitHub cada quince minutos; el resultado queda en la base.

Pedir un backtest

Escribí los ids de API-Football separados por coma. Si no sabés el id, buscá el país abajo y tocá la liga. La primera temporada solo precalienta; las demás se evalúan.

Un pedido se atiende en la próxima ronda de GitHub (cada 15 minutos). Cada liga cuesta un pedido a la API por temporada más dos. La clave queda guardada en este navegador.
